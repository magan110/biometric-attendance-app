## Launch post draft

I built Face Attendance, a Flutter prototype exploring a camera-based attendance flow with ML Kit face detection, TFLite face embeddings, face-quality checks, blink/liveness signals, and local SQLite enrollment.

The project is open for technical review and experimentation. It is a prototype, not a production-ready identity or anti-spoofing system. Biometric data is sensitive, and any real deployment needs informed consent, a clear retention/deletion policy, security review, accuracy evaluation, and a non-biometric alternative.
